# 04. 에러 코드 표

> 에러 코드 정렬 규약: HTTP 상태코드 오름차순 → 같은 코드 내에서는 흐름 순
> 

**공통 (global)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| INVALID_REQUEST | 요청 값 오류 (validation 실패, 타입 불일치) | 400 |
| UNAUTHORIZED | 인증 정보 무효/만료 | 401 |
| FORBIDDEN | 접근 권한 없음(관리자 등) | 403 |
| METHOD_NOT_ALLOWED | 지원하지 않는 HTTP 메서드 | 405 |
| TOO_MANY_REQUESTS | 요청 횟수 초과(매크로 의심) | 429 |
| INTERNAL_SERVER_ERROR | 서버 내부 오류 (fallback) | 500 |
| EXTERNAL_API_ERROR | 외부 연동(PG, 서울시 도시데이터 등) 통신 실패 | 502 |

**사용자 (users)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| DUPLICATE_LOGIN_ID | 아이디/이메일/닉네임/전화번호 중복 | 409 |
| USER_NOT_FOUND | 사용자를 찾을 수 없음 | 404 |
| USER_INACTIVE | 비활성/정지 계정(`users.status`) | 403 |
| USER_NOT_VERIFIED | 본인 인증 미완료(`users.is_verified=false`) — 예매 불가 | 403 |
| DUPLICATE_VERIFICATION | 이미 다른 계정에서 인증된 본인(`users.ci` 중복) | 409 |
| VERIFICATION_FAILED | PortOne 본인인증 조회/처리 실패 | - |
| TICKET_EXISTS_ON_WITHDRAWAL | 정산 미완료 티켓 보유로 탈퇴 불가 | 409 |
| INVALID_PASSWORD | 현재 비밀번호 불일치 | 400 |

**기준 데이터 (teams, stadiums, seat_zones)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| TEAM_NOT_FOUND | 구단을 찾을 수 없음 | 404 |
| STADIUM_NOT_FOUND | 구장을 찾을 수 없음 | 404 |
| ZONE_NOT_FOUND | 좌석 구역을 찾을 수 없음 | 404 |

**경기 (games)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| GAME_NOT_FOUND | 경기를 찾을 수 없음 | 404 |
| SAME_TEAM_MATCH | 홈팀·원정팀이 동일(`homeTeamId == awayTeamId`) | 400 |
| DUPLICATE_GAME | 동일 구장·동일 일시에 이미 등록된 경기가 있음(`uk_games_stadium_game_at`) | 409 |
| BOOKING_NOT_OPEN | 예매 가능 상태가 아님(`booking_status != OPEN`) | 409 |
| INVALID_BOOKING_STATUS_TRANSITION | 허용되지 않은 예매 상태 전이 | 409 |

**대기열 (queue)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| QUEUE_TOKEN_REQUIRED | 입장 토큰 없음(대기열 우회 차단) | 403 |
| QUEUE_TOKEN_INVALID | 유효하지 않은 입장 토큰 | 403 |
| QUEUE_TOKEN_ALREADY_USED | 이미 사용된 입장 토큰<br>(`admission_tokens.status=USED`) | 409 |
| QUEUE_TOKEN_EXPIRED | 만료된 입장 토큰 (`status=EXPIRED`) | 410 |
| QUEUE_TOKEN_REVOKED | 대기 취소 또는 SSE 재연결 유예시간 만료로 취소된 입장 토큰<br>(`admission_tokens.status=REVOKED`) | 410 |
| QUEUE_TOKEN_NOT_EXPIRED | 아직 만료되지 않은 토큰에 만료 처리 시도 | 409 |
| QUEUE_TOKEN_BROWSING_EXPIRED | 최초 좌석 탐색 시간 만료 | 410 |
| QUEUE_TOKEN_BROWSING_NOT_EXPIRED | 탐색 시간이 아직 안 지남 | 409 |
| QUEUE_ENTRY_NOT_FOUND | 대기열 진입 이력이 없음 | 404 |
| QUEUE_ENTRY_REENTRY_NOT_ALLOWED | 재진입이 허용되지 않는 상태 | 409 |
| QUEUE_ENTRY_ADMISSION_NOT_ALLOWED | 입장 허용이 불가한 상태 | 409 |
| QUEUE_ENTRY_CANCELLATION_NOT_ALLOWED | 취소가 불가한 상태 | 409 |
| QUEUE_ENTRY_CANCELLATION_TOKEN_REQUIRED | 취소 처리에 토큰 정보 필요 | 400 |
| QUEUE_ENTRY_EVENT_ID_REQUIRED /<br>GAME_ID_INVALID / USER_ID_INVALID /<br>REQUESTED_AT_REQUIRED / EVENT_REQUIRED | Kafka 이벤트 페이로드 검증 실패 | 400 |
| QUEUE_ADMISSION_INTERRUPTED | 자동 입장 처리 중 중단 발생 | 503 |
| QUEUE_REDIS_MEMBER_INVALID | Redis ZSet 멤버 형식 오류 | 503 |
| QUEUE_REDIS_KEY_INVALID | Redis 대기열 Key 형식 오류 | 503 |
| QUEUE_EVENT_PUBLISH_FAILED | Kafka 대기열 진입 이벤트 발행 실패 | 503 |
| QUEUE_ADMISSION_METRIC_SEARCH_CONDITION_INVALID | 관리자 입장 지표 조회 조건이 올바르지 않음(기간 역전 또는 366일 초과) | 400 |

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| ALREADY_IN_QUEUE | 동일 경기 대기열 중복 진입 | 409 |
| QUEUE_INVALID_STATUS | 유효하지 않은 상태(대기열 상태 변화 시 사용) | 409 |
| QUEUE_REGISTRATION_FAILED | Redis ZSet 대기열 등록 실패 (서비스 문제 생김) | 503 |

**좌석 (seats, game_seats)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| SEAT_NOT_FOUND | 물리 좌석을 찾을 수 없음 | 404 |
| GAME_SEAT_NOT_FOUND | 경기 좌석 재고를 찾을 수 없음 | 404 |
| GAME_SEAT_NOT_IN_GAME | 요청 좌석이 해당 경기에 속하지 않음 | 400 |
| MAX_SEAT_COUNT_EXCEEDED | 1인당 최대 예매 좌석 수 초과 | 400 |
| SEAT_ALREADY_HELD | 이미 선점된 좌석(`status=HELD`) | 409 |
| SEAT_ALREADY_SOLD | 이미 판매된 좌석(`status=SOLD`) | 409 |
| SEAT_BLOCKED | 판매 차단된 좌석(`status=BLOCKED`) | 409 |
| SEAT_INVENTORY_ALREADY_OPENED | 이미 좌석 재고가 오픈된 경기 | 409 |
| SEAT_INVENTORY_NOT_OPENED | 좌석 재고가 아직 오픈되지 않음 | 409 |
| LOCK_FAILED | 락 획득 실패 | 409 |
| INVALID_PRICE | 좌석 가격 값 오류 | 400 |
| ZONE_NOT_FOUND | 좌석 구역을 찾을 수 없음 | 404 |

**예약/선점 (reservations)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| RESERVATION_ACCESS_DENIED | 타인 예약 접근 | 403 |
| RESERVATION_NOT_FOUND | 예약을 찾을 수 없음 | 404 |
| RESERVATION_SEAT_NOT_FOUND | 예약 좌석을 찾을 수 없음 | 404 |
| INVALID_RESERVATION_STATUS | 예약 상태가 요청과 맞지 않음(HOLDING 아님) | 409 |
| RESERVATION_ALREADY_ORDERED | 이미 주문이 생성된 예약(`uk_orders_reservation`) | 409 |
| HOLD_EXTENSION_LIMIT_EXCEEDED | HOLD 연장 상한(최초 선점 + 18분) 초과 | 409 |
| PRE_RESERVATION_EXPIRED | 선점 시간 만료(`reservations.status=EXPIRED`) | 410 |

**주문 (orders)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| ORDER_NOT_FOUND | 주문을 찾을 수 없음 | 404 |
| INVALID_ORDER_STATUS | 결제 가능한 주문 상태가 아님 | 409 |
| ORDER_EXPIRED | 결제 제한 시각(`paymentDeadline`) 경과 | 410 |

**결제 (payments)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| IDEMPOTENCY_KEY_REQUIRED | `Idempotency-Key` 헤더 누락 또는 공백 | 400 |
| PAYMENT_CALLBACK_MISMATCH | PG 주문번호 또는 금액이 로컬 결제 내역과 불일치 | 400 |
| PAYMENT_ACCESS_DENIED | 해당 결제 처리 권한 없음(다른 사용자의 결제/주문) | 403 |
| PAYMENT_NOT_FOUND | 결제 내역을 찾을 수 없음 | 404 |
| IDEMPOTENCY_KEY_CONFLICT | 동일 멱등키가 다른 주문의 결제에 이미 사용됨 | 409 |
| PAYMENT_ALREADY_FINALIZED | 이미 종결된 결제(FAILED/CANCELED 등)에 대한 승인 재시도 | 409 |
| PAYMENT_CANCEL_STATUS_UNKNOWN | 승인 요청과 재조회 후에도 PG 실제 상태를 확인할 수 없음(자동 복구 작업 등록) | 502 |
| PAYMENT_LOCAL_APPLY_FAILED | PG 승인은 확인됐으나 로컬 상태 반영에 실패(자동 PG 취소 등록) | 502 |
| PG_CANCEL_FAILED | Toss 부분 취소 실패, 재시도 필요(`payment_cancels.status=FAILED`) | 502 |

**티켓 (tickets)**

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| TICKET_ACCESS_DENIED | 타인 티켓 접근 | 403 |
| TICKET_NOT_FOUND | 티켓을 찾을 수 없음 | 404 |
| TICKET_ALREADY_USED | 이미 사용된 티켓(`USED_ENTERED`/`USED_NO_SHOW`) | 409 |
| TICKET_ALREADY_CANCELED | 이미 취소된 티켓(`status=CANCELED`) | 409 |
| TICKET_CANCEL_DEADLINE_PASSED | 취소 가능 시점 경과 | 409 |
| TICKET_REFUND_IN_PROGRESS | 환불 진행 중인 티켓(`status=REFUND_PENDING`) | 409 |
| TICKET_REFUND_FAILED_RETRY_REQUIRED | 환불 실패 상태, 재시도가 필요한 티켓(`status=REFUND_FAILED`) | 409 |
| TICKET_ALREADY_REFUNDED | 이미 환불 완료된 티켓(`status=REFUNDED`) | 409 |
| INVALID_STATE_TRANSITION | 재시도 등 허용되지 않은 상태 전이 요청<br>(예: `REFUND_FAILED`가 아닌 티켓의 재시도) | 409 |
